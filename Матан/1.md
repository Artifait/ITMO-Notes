# Поле вещественных чисел

## Язык кванторов и действия над множествами:
- ∀ - Любой
- ∃ - существует
- ∧ - и
- ∨ - или

## Опр: A и B - множества универсального множества U
1. Пересечение  A ∧ B = { x ∈ U | (x ∈ A) и (x ∈ B)}
2. Объеденение  A ∨ B = { x ∈ U | (x ∈ A) или (x ∈ B)}
3. Разность     A ⧵ B = { x ∈ U | (x ∈ A) и (x ∉ B)}
4. Симетрическая разность A Δ B = (A \ B) ∨ (B \ A)

## Сравнение множеств
1) A c B ⟺ ∀ x ∈ A x ∈ B (A подмножество B)
2) A = B ⟺ (A c B) ∧ (B c A)

## Закон де Моргана
1) $\overline{A \land B}$ = $\overline{A}$ ∨ $\overline{B}$
2) $\overline{A \lor B}$ = $\overline{A}$ ∧ $\overline{B}$


## Закон де Моргана для произвольного(в том числе бесконечного) семейства множеств - в формулировке через дополнение относительного множества X 
 
 ## Закон де Моргана для произвольного семейства множеств

Пусть $I$ — произвольное множество индексов, а $\{A_i\}_{i \in I}$ — семейство подмножеств универсального множества $X$.

### Формулировка законов
1. **Дополнение объединения:**
$$X \setminus \bigcup_{i \in I} A_i = \bigcap_{i \in I} (X \setminus A_i)$$

2. **Дополнение пересечения:**
$$X \setminus \bigcap_{i \in I} A_i = \bigcup_{i \in I} (X \setminus A_i)$$


## Опр. Декартового произведения множеств A и B на множество, состоящие из упоряд пар

A x B = {(a, b) | a ∈ A ∧ b ∈ B} 

## Опр. X и Y - множества Отображением(функцией)
$f$ : X ⟶ Y на правило, которое каждому эл-ту x ∈ X, сопоставляет единственный элемент y = $f(x)$

## Опр. Областью значение или образом $f$ называют множество тех элементов Y, которые имееют прообраз X:

# Главные определения
- Отображение (функция) — это $f$. Это само правило, закон или зависимость, по которому одному числу ставится в соответствие другое.

- Образ — это $y$ (или $f(x)$). Это результат применения отображения, то есть значение функции в конкретной точке.

- Прообраз — это $x$. Это аргумент (элемент исходного множества), который мы подставляем в функцию, чтобы получить $y$.
